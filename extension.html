Browser extension (beta)

Ratings on the trading sites you already use.

Switch on the BluntX extension in a supported tab and each coin on the page gets a Low risk, Caution or High risk badge with its risk score. The side panel lists the findings behind every rating. It uses the same points model as the checker. On any other site, paste an address into the side panel, or select an address and choose Check with BluntX.

Download v0.3 (.zip) See the scoring rules

Beta, not yet on the Chrome Web Store. Desktop Chrome and other Chromium browsers. No wallet access, no transactions.

  1. Download and unzip bluntx-extension.zip.
  2. Open chrome://extensions in Chrome.
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and select the unzipped bluntx-extension folder.
  5. Open a supported site, click the BluntX icon and switch On for this tab.

Supported sites

Auto-scan these pages, or paste an address anywhere.

When you switch the extension on for a tab, it reads token or contract addresses from the page and the URL. BluntX is independent and is not affiliated with these sites, nor with DexScreener, RugCheck, GoPlus or Honeypot.is, which supply the public data behind each rating. The extension runs the same checks as this website.

  • pump.fun
  • Birdeye (birdeye.so and birdeyeterminal.com)
  • GMGN (gmgn.ai)
  • Photon (photon-sol.tinyastro.io)
  • BullX (bullx.io and neo.bullx.io)
  • Axiom (axiom.trade)
  • Raydium (raydium.io)
  • Jupiter (jup.ag)
  • Solscan (solscan.io)
  • DexScreener (dexscreener.com)
  • Moonshot (moonshot.com)
  • letsbonk.fun
  • Uniswap (app.uniswap.org)
  • Etherscan, BscScan and Basescan
  • Four.meme
  • DEXTools (dextools.io)
  • GeckoTerminal
  • CoinGecko token pages, when a contract address is present
  • RugCheck (rugcheck.xyz)

On other sites, open the side panel and paste an address, or select an address and choose Check with BluntX. Auto-scan is not available there. BullX currently shows trading as disabled on its own site; address checks still work if a token page is open.
